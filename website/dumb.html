PLAIN ENGLISH EXPLANATION

The Simple Guide to Minecraft Performance

No math degree required. Here is exactly what CPS, DPS, MSPT, FFI, Vanilla, and Oxide actually mean and how they work together.

01

What is a Chunk?

Minecraft cuts the world into vertical columns called Chunks.

Each chunk is 16 blocks wide, 16 blocks long, and 384 blocks tall (from Y = -64 to Y = 320). That means building just one chunk requires calculating and placing 98,304 individual blocks (stone, dirt, caves, water, air, ores).

02

What is CPS? (Chunks Per Second)

CPS measures how many full 16x384x16 chunk columns the server can generate from scratch in one single second.

Vanilla Minecraft (~20 CPS)

Takes 5 to 6 hours to pre-generate a 10,000 x 10,000 map. Players running or flying cause massive server lag spikes.

Oxide Native (~800+ CPS)

Generates the entire 10,000 x 10,000 world in under 9 minutes. Elytra flight causes zero lag.

03

What is DPS? (Density Evaluations Per Second)

Minecraft does not guess where mountains and caves are. It evaluates complex 3D mathematical noise curves called Density Functions.

DPS is the number of 3D math equations the engine solves per second to figure out if a position in the world should be solid rock, open cave, or water.

The Connection Between CPS and DPS:

To generate 800 CPS, Oxide solves over 1,000,000 density math equations per second and writes over 78,000,000 blocks per second into server memory.

04

What is MSPT? (Milliseconds Per Tick)

A Minecraft server runs at 20 ticks per second (TPS). That means the server has exactly 50 milliseconds (ms) to compute everything in the world before the next tick starts.

MSPT is how many milliseconds the server actually spent doing work during that 50ms window.

MSPT > 50 ms (LAG)

The server cannot finish work in time. TPS drops below 20, mobs stutter, block breaks rubberband.

MSPT < 2 ms (LIGHTNING FAST)

Oxide finishes generating terrain in 0.83 ms, leaving 98% of the CPU free for players, redstone, and entities.

05

What Vanilla Java is Doing (Why it's Slow)

Official Minecraft is written in Java. When vanilla generates terrain:

  • It creates millions of temporary Java objects (Vector3f, BlockPos, Holder) every second.
  • The Java Garbage Collector (GC) has to constantly pause the server to clean up these discarded objects.
  • It evaluates complex noise functions through slow, virtual Java method calls one block at a time.
06

What Oxide is Doing (Why it's Fast)

Oxide takes over the heavy math and runs it in Rust:

  • Zero Garbage Collection: Rust allocates flat memory buffers and frees them immediately. Zero GC pauses.
  • SIMD Vectorization: Solves math for 8 to 16 blocks simultaneously using direct CPU vector instructions.
  • Cell Skipping: If a 4x8x4 box is deep underground, Oxide instantly marks all 128 blocks solid rock without wasting time calculating each block.
07

What is Panama FFI?

FFI (Foreign Function Interface) is a bridge that lets Java talk directly to native Rust machine code in the same process.

Java 22+ introduced the Foreign Function and Memory API (Project Panama). Instead of slow legacy JNI wrappers, Panama passes raw memory addresses directly to Rust with near-zero overhead.

09

What is Pacside? (Zero-Latency Chunk Streaming)

Generating chunks fast is only half the battle. When a player flies with an Elytra at 30 m/s, the server has to serialize and send chunks across the network before the player hits the unloaded void.

Pacside is Oxide's predictive chunk streaming engine:

  • Predictive Trajectory Prefetching: Tracks player velocity vectors and pre-loads a 60-degree forward cone of chunks 5–7 chunks ahead of flight.
  • Off-Heap Native Packet Cache: Caches pre-compressed network payloads in native RAM (32,768 chunks), eliminating repeated Java Netty Zlib compression passes.
