Sessions

Each track is one Claude session on oci-v3, logged into its own account, working in its own git worktree and benchmarking on the bench VPS. A session that finishes is restarted after a minute; one that sits idle for twenty minutes is told to carry on. Results land on the progress page.

Logging an account in

  1. Open a track's terminal. A session that is not logged in shows Claude's first-run screens; pick a theme and choose to log in with a Claude account.
  2. Claude prints a link. Open it in a browser where you are signed in to the account for this track, approve, and copy the code it shows.
  3. Paste the code into the terminal and press Enter. Accept the trust prompt for the folder and the prompt for skipping permissions; the session starts on the track by itself.
  4. Use a different account per track. An account that is out of quota still logs in; its session waits and is nudged again every twenty minutes until the quota resets.

Terminals are open to one GitHub account only, not to the rest of the organisation. Detach without stopping anything by closing the tab.
