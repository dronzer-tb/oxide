The stack

Three pieces, one problem.

Getting a chunk from noise math onto a player's screen has three separate bottlenecks. Each project kills one of them.

Oxide

World generation core

The whole vanilla worldgen pipeline rewritten in Rust — noise routers, 6-axis biome climate search, surface rules, aquifers, carvers, ore veins, structure placement and native Jigsaw assembly. Reads your existing datapacks unchanged.

  • Bit-exact Xoroshiro128++ and Java RNG parity
  • 150+ datapacks layered (Terralith, Incendium, Yggdrasil)
  • SIMD density interpolation, cell-level culling
  • Panama FFI — no JNI, no copies

Pacside

Off-heap chunk streaming

Generating fast is useless if the server can't ship the chunks out. Pacside keeps pre-compressed chunk packets in native memory and predicts where you're flying, warming the terrain ahead of you before the client ever asks.

  • 32-way sharded LRU cache, 32k chunks off-heap
  • Velocity-cone prefetch, 16 chunks of lookahead
  • Tick-paced token bucket — flat 20.0 TPS under load
  • Zero GC pressure, zero network round trips

Vertex Engine

Server fork & module SPI

A Paper/Folia fork that hands native code raw pointers to chunk section memory. No Bukkit wrapper objects, no BlockState conversion, no per-block calls across the boundary. Oxide writes terrain directly where the server already wanted it.

  • Zero-copy writes into LevelChunkSection
  • Concurrent section writes across cores
  • Doubles throughput to 1,550+ CPS
  • Drop-in module SPI for other native engines

How a chunk gets made

From noise to your screen.

Every step below runs in native code. The Java server only finds out a chunk exists once the memory is already written.

01
Datapack load 150+ packs parsed and merged into one registry — biomes, density functions, surface rules, structure sets.
oxide-datapack
02
Noise router Density function graph compiled once, then evaluated with SIMD interpolation across a 4×8×4 cell grid.
oxide-noise
03
Biome resolution 6-axis climate point searched against a KD-tree. Uniform sections short-circuit on 8-corner coherence.
oxide-biome
04
Terrain fill Every voxel from Y −64 to 320 resolved against density and aquifer state. Cell bounds cull ~70% of interpolation.
oxide-chunkgen
05
Surface, carvers, ores 15 surface rule conditions, badlands banding, cave and canyon carvers, ore vein placement.
oxide-chunkgen
06
Structures & Jigsaw Random-spread candidates, stronghold rings, then recursive 3D Jigsaw assembly with AABB collision solving.
oxide-structures
07
Handoff Vertex writes sections straight into server memory. Plugin mode copies once through Panama.
oxide-ffi
08
Stream out Pacside compresses the packet once, caches it off-heap, and pushes it ahead of the player's flight path.
pacside
