Deep Engineering

How Oxide Works Under the Hood

Oxide is not an approximation. It is an exact mathematical reconstruction of vanilla 26.2 algorithms compiled to native SIMD machine code.

⚡

SIMD 3D Noise Terrain

Evaluates continuous density function graphs (`final_density`), 3D cheese/noodle caves, and $4 \times 8 \times 4$ trilinear cell interpolation with zero JVM object allocations.

🌐

6-Axis Climate Biome Grid

Multi-noise KD search tree mapping temperature, humidity, continentalness, erosion, weirdness, and depth into exact 3D biome quart arrays.

🏜️

15 Surface Rule Conditions

Full rule tree evaluation: bedrock floors, deepslate transitions, ocean floors, height-adjusted temperature snow line, and 64-layer procedural Badlands terracotta banding.

🌊

Noise-Based Aquifers

Computes underground fluid bodies over a $16 \times 12 \times 16$ grid with barrier-noise pressure walls, preventing flooded caves from spilling into dry chambers.

⛏️

Cave & Canyon Carvers

Step-by-step tunnel walking with room forks, pitch/yaw variations, and ravine width factors. Directly integrates with aquifers to fill submerged caves with fluid.

🏰

Stronghold & Structure Placement

Bit-exact `random_spread` candidate selection and concentric rings stronghold math radiating from $(0, 0)$ matching vanilla seed calculations.

Next-Gen Pipeline

The Vertex Engine Advantage

Bukkit's `ChunkGenerator` API was built for Java plugins, forcing intermediate wrapper buffers and per-position FFI downcalls.

Vertex Engine is a minimal Folia fork that exposes a direct native module SPI (`ChunkTarget`). Oxide writes blocks and 3D biomes directly into Folia's internal `LevelChunkSection` palette buffer in a single atomic memory write — unlocking 1,500+ CPS.

Single JAR Dual-Mode Zero GC Pauses
// Java Panama FFI Bridge (Oxide Native) public final class OxideChunkHook implements ChunkGenerationHook { @Override public HookResult generateChunk(ChunkRequest request, ChunkTarget target) { // Direct zero-copy write into LevelChunkSection memory long status = OxideNative.generateChunkDirect( handle, request.chunkX(), request.chunkZ(), target.blockBufferAddress(), target.biomeBufferAddress() ); return status == 0 ? HookResult.SUCCESS : HookResult.FALLBACK; } }
Extensibility

Support for 150+ Custom Datapacks

Oxide is 100% data-driven. It never hardcodes noise parameters into binaries — it interprets your worldgen datapacks directly.

Multi-Datapack Layering (`load_datapack_stack`)

Install Terralith, Incendium, Nullscape, Structory, and custom server datapacks together. Oxide merges all namespaces and registry overlays (`worldgen/density_function`, `noise_settings`, `biome`, `configured_carver`) into a unified graph before resolving dependencies.

# In plugins/OxideDebug/config.yml datapack-path: "datapack" # Stacks vanilla 26.2 + all installed datapacks dynamically dimension-override: "minecraft:overworld"
